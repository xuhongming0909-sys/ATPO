## 一、业务目标

- 自动申购：可转债（沪深）+ 各市场新股（沪主板、深主板、创业板、科创板、北交所）。
- 中签提醒：T+1 晚 / T+2 早自动查询，T+2 缴款截止 16:00 前提醒。
- 双实例多账户：E:\同花顺 与 E:\同花顺2 各管理最多 10 户，严格串行，目标约 20 户；平安/华宝/中信建投均可保留。
- 可复制性：项目文件夹复制到 Windows 电脑后，可通过统一 setup、doctor、配置模板和错误提示初始化运行。

## 三、关键时间节点

- T 日 9:30–15:00 申购窗口，系统 10:00 执行。
- T+1 晚 22:00 查中签；T+2 早 08:00 补查；T+2 16:00 缴款截止。

## 四、形态与技术路线

```text
Windows 本机
  scheduler/    Windows 计划任务
  data_fetch/   东方财富打新日历
  execution/    同花顺双实例 + jqktrader/pywinauto
  notification/ Server酱
  shared/       路径、配置、DPAPI、错误、doctor、GUI 锁
```

- 同花顺主界面保持登录，按“下拉→点户→重新下拉”补登；F12 带令牌启动 xiadan。
- 每客户端账户按菜单/下拉文本动态匹配 config；menu_row 只作缓存，不能作为成功判据。
- 两个客户端永远串行；窗口/PID 按精确 exe 路径归属，歧义即停止。
- “委托下单”资金账号/密码/验证码登录框截图关闭后继续；其他安全验证或人工确认弹窗只报告并停止，不自动绕过。

## 五、模块与账户模型

| 模块 | 职责 |
|---|---|
| data_fetch/ | 新股+可转债日历规范化 |
| scheduler/ | 日历、申购、中签任务编排与安装脚本 |
| execution/ | 发现、登录、换户、申购、F8、中签、台账 |
| notification/ | 日历/申购/中签/异常推送 |
| shared/ | 路径、配置、DPAPI、错误、诊断、GUI 锁 |

账户模型：id、可选 display_name、broker、account_type、enabled、permissions（cb/cyb/kcb/bj）、strategy。完整资金账号只在 config/secrets.yaml；密码仅 DPAPI 密文。新账户接入只改 config/secrets，不改代码。

## 六、安全与风险

- 客户端自动化属券商协议灰色地带；客户端升级可能使控件脚本失效。
- 仅限本机自用，不面向他人代操作。
- 自动申购不等于盈利；系统只执行与提醒。
- execution.mode=live + --live 双确认；每单台账、F8、截图；不明结果禁止重试。

## 九、任务生命周期、幂等与错过后补

- GUI 任务按 THS 登录账户严格串行（shared/gui_lock）；一个账户失败不阻塞其他账户。
- 每个任务启动/接管精确 exe 路径下的 hexin/xiadan，并记录启动 PID 归属、preexisting/managed、start/close 状态和错误码到 runtime_data/client_lifecycle/。
- execution.lifecycle.close_after_task、close_preexisting 为 true 时，任务结束温和关闭；关闭超时只报告 CLIENT_CLOSE_FAILED，禁止强杀。
- runtime_data/task_state.json 按 task/date/mode 幂等记录 status、completed_at、receipt_status、error；dry_run 与 live 分离。完整 THS 用户名、显示名、状态和错误保留，完整资金账号和核心凭据排除。
- python run.py catch-up --date YYYY-MM-DD [--live] 补当日任务：日历未成功推送则补；申购只在 catchup.subscribe_skip_after 前补，过期记 skipped_expired；中签无有效结果或回执未成功则按间隔补查，“数据未公布”不是最终无中签。
- 申购成功后不因回执失败重复下单，只重试标准回执；不确定订单状态记 blocked_uncertain，禁止自动重试。
- 标准回执契约：notification.receipts.send_receipt(kind, data)，kind 为 login/subscribe/allotment；catch-up 只记录 receipt_status，不修改 notification 或执行模块。
- Windows 计划任务保留原定时任务，并增加登录后和网络连接事件后的 catch-up --live 任务；全部通过 scheduler/run32.cmd / run64.cmd 统一入口运行。
