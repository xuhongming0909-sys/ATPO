# Operations 规格：登录、客户端生命周期、错过后补与回执

## 1. 登录账户选择

目标是登录所有“可直接登录账户”，或达到单实例 10 个已登录账户上限。

1. 读取同花顺主界面账户下拉行。
2. 按 `display_name`、`id` 和配置别名匹配账户。
3. 只有唯一匹配且具备姓名/别名特征的行才作为可直接登录候选。
4. 仅有证券公司+资金账号、缺少姓名/别名的行标记 `login_required`，不主动点击。
5. 人工缓存 `menu_row` 只能辅助，不得替代文本匹配。
6. 已登录账户优先计入 10 户上限，不重复点击。

账户状态新增：

- `ready`：已登录且资金账号复核通过。
- `already_logged_in`：运行前已登录，复核通过。
- `login_required`：需填写资金账号/密码/验证码，跳过。
- `dialog_closed`：误点后弹出委托登录框，已关闭并跳过。
- `not_selected`：身份无法唯一确认，不点击。
- `wrong_account`：点击后上下文不符。

## 2. 委托下单登录弹窗

同时出现“委托下单/证券公司/资金账号/交易密码/验证码”中的登录特征时：

1. 立即关闭该登录窗口，优先于其他 GUI 操作。
2. 将目标账户记录为 `dialog_closed` 或 `login_required`。
3. 继续处理下一个可直接登录账户。
4. 不填写密码、不识别验证码、不点击“登录”。
5. 其他安全验证或人工处理弹窗仍停止当前客户端并报告。

日志和推送显示完整 THS 用户名、账户显示名、状态、错误码、错误原因和截图路径；完整资金账号、密码和验证码等核心凭据不显示。

## 3. 客户端生命周期

每个 THS 登录账户遵循：

```text
获取全局 GUI 锁
  → 启动目标 hexin/xiadan（必要时）
  → 登录一个 THS 账户并处理资金账户
  → 执行该账户阶段任务
  → 保存结果/截图
  → 温和关闭本次该 THS 账户的客户端
  → 释放锁
```

- 进程归属按精确 exe 路径和启动 PID 保存在 `runtime_data/`。
- 默认温和关闭：先发关闭消息并等待，禁止直接强杀。
- 已存在的客户端标记 `preexisting`；默认在任务结束后温和关闭，可由 `execution.lifecycle.close_preexisting` 调整。
- 关闭失败必须报告 `CLIENT_CLOSE_FAILED`，不得伪报完成。
- 多个 THS 登录账户永远独立串行（全局 GUI 锁 + 逐账户独立生命周期）。

## 4. 开机联网后错过后补

新增当日任务状态，至少记录任务名、业务日期、状态、完成时间、回执状态和错误（仅凭据脱敏）。

- 日历推送：当日未成功推送则补发。
- 申购：只在 `subscribe_window` 内补做；窗口后标记 `skipped_expired`，不补真实委托。
- 中签查询：未得到有效结果或未成功推送时继续补查；“数据未公布”不是最终结果。
- 已成功完成且已推送的任务不得重复执行。
- 开机/联网触发运行补任务；原定时任务继续保留。
- dry-run 与 live 状态分开记录。

## 5. 推送回执模板

统一三类：

### 登录回执

标题：

```text
[登录回执][10/17] 账户 13｜成功 12｜失败 1
```

正文：

```text
日期：2026-10-17
账户总数：13
成功：12
失败：1
[THS: mx_525378109] 账户 9｜成功 8｜失败 1
1. 账户：平安证券-张*龙｜资金账号：326219242115｜THS：mx_525378109｜事件：登录成功｜状态码：ready
2. 账户：中信建投证券-许*鸣融｜THS：mx_525378109｜结果：失败｜状态：dialog_closed｜原因：资金账户登录弹窗已关闭
下一步：需登录账户由人工在客户端完成密码/验证码。
```

### 申购回执

标题：

```text
[申购回执][10/17] 成功 9｜跳过 1｜失败 0
```

正文包含日期、时间、账户名、完整资金账号、THS 用户名、标的、数量、状态、失败原因和下一步。

### 中签回执

标题：

```text
[中签回执][10/17] 中签 2 户
```

无中签时标题为 `[中签回执][10/17] 无中签`。正文包含账户名、标的、中签数量、缴款提醒；没有结果时明确写“数据未公布，将继续补查”。

模板版本写入配置，渲染函数保持纯函数。普通账户识别信息完整显示；推送前只删除 `password`、`captcha`、SendKey、token、DPAPI 密文等凭据字段。证券代码、资金账号和资金账号尾号属于业务识别字段，允许显示。
