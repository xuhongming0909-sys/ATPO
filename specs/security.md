# Security 规格

## 凭据与账户信息
- 本项目仅用户本人本机使用。THS 用户名、券商显示名、完整资金账号、资金账号尾号等普通账户识别信息可以进入本机日志、运行时结果和推送，用于准确识别账户。
- 交易密码、验证码、SendKey、token、DPAPI 密文不进 git、不进日志、不进推送。
- 交易密码只以 Windows DPAPI 密文存 `config/secrets.yaml`；完整资金账号的配置来源仍只存该文件。
- 运行时状态、订单台账、截图文件名可使用账户 ID、显示名、资金账号或尾号；不得写入交易密码、验证码或密钥。

## 实盘
- `execution.mode=live` 与命令行 `--live` 同时满足才允许真实委托。
- 同一账户、同一申购代码、同一交易日只允许一次提交。
- `unknown`、`submitted_unverified` 状态必须阻断自动重试。
- 每次实盘操作必须保存结果台账和客户端截图。

## 人工干预
- 短信、动态口令、人工安全验证对话框：立即停止后续操作并推送，绝不绕过（2026-10-24 用户拍板保留）。
- 「委托下单」资金户登录框：允许自动处理，优先级 = ①OCR 数字验证码直填 ②DPAPI 密码自动填充+验证码+点登录（2026-10-24 用户批准）。任何一步失败立即回退「关框跳过」。
- 密码仅经 DPAPI 解密后直接写入客户端密码框（WM_SETTEXT），不打印、不日志、不推送、不过剪贴板。
- 系统仍不点击未知对话框的“确定/确认”。

## 范围
- 仅限本机自用，不面向他人提供代操作服务。

## 可复制安全边界

- `config/secrets.yaml` 被 git 忽略；项目复制包不得默认携带真实 secrets。
- Windows DPAPI 密文只对原电脑原用户有效。换机/换用户后解密失败必须重新录入，不得回退明文。
- `doctor`、日志、诊断包、推送可以显示完整资金账号和尾号用于本人识别；不得显示交易密码、验证码、SendKey、token 或 DPAPI 密文。
- setup、preflight、doctor 永不自动下单；live 仍需 `execution.mode=live` + `--live` 双确认。
- 安装/复制失败不得删除现有 config、secrets、runtime_data、订单台账和截图。
