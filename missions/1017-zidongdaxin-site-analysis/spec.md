# Mission Spec 模板

## 任务类型
分析

## 目标
在真实网络请求和页面证据基础上，解释 zidongdaxin.com 的业务流程、前后端接口、调度/交易链路、部署特征与安全风险。

## 范围
只分析公开站点、公开页面资源、DNS/TLS/HTTP 元数据及与本地 `自动打新` 项目的关系；不修改生产站点，不提交表单，不登录，不触发任何打新/交易动作。

## 约束
- 只读公开信息，不绕过认证或访问控制。
- 不收集、保存或输出密码、Cookie 会话值、密钥。
- 不修改项目业务代码和正式 `specs/*.md`。
- 结论必须区分“直接证据”和“推断”。

## 对正式 spec 的影响
无。当前是外部站点分析，不改变本项目正式需求。
