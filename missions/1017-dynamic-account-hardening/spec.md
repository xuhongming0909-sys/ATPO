# Mission Spec

## 任务类型
修复 + 实现

## 目标
让单个同花顺实例按当前客户端实际账户集合动态运行，不硬编码券商或账户；同时消除重复委托风险，修复计划任务和运行前检查。

## 范围
- 账户选择：BootLogin、申购、中签查询按当前 hexin/xiadan 可用账户动态匹配 config，所有券商均可参与，单实例上限仍为 10。
- 实盘安全：新增每日订单状态台账；同一账户、同一申购代码、同一交易日只允许一次提交；不确定结果不得自动重试。
- 批量申购：提交后按当日委托逐笔核验，不再仅凭弹窗消息判定成功。
- 调度：修复 Windows 计划任务命令、工作目录和补跑配置；申购时段外不实盘。
- 运行检查：新增只读 preflight。
- 文档：同步 specs、INDEX、README。
- 不处理：双同花顺实例、20 户扩展、WebUI 重构、券商协议办理。

## 约束
- 不硬编码券商名、账户 ID、账户行号。
- 华宝、中信建投当前登录失败只记当前不可用，不得永久排除。
- 密码、验证码弹窗仍立即停止；不自动填写、不绕过。
- 完整资金账号只存 config/secrets.yaml；日志、台账、推送只允许哈希或脱敏值。
- execution/ 测试只用模拟/桩对象，不触碰真实客户端。
- 不修改 AGENTS.md、templates/。

## 对正式 spec 的影响
更新 specs/spec.md、specs/execution.md、specs/requirements.md，并新增 specs/security.md。
