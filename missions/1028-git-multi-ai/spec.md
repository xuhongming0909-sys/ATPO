## 任务类型
分析 + 需求更新 + 实现准备

## 目标
为“多个 AI 同时编码”建立不互相覆盖的 git 协作方案，并在获得远程仓库地址后把当前项目安全推送到 git。

## 范围
- 检查本地 git 状态、分支、远程、敏感信息风险。
- 设计多 AI 并行工作的分支/提交/文件归属规则。
- 远程仓库地址确认后：添加 remote、建立基线提交、推送。
- 计划新增 `docs/multi_ai_git_workflow.md`（正式协作说明）并登记 `INDEX.md`。

## 约束
- 不修改 `AGENTS.md`、`templates/` 下模板。
- 不把 `config/secrets.yaml`、运行时数据、虚拟环境推入 git。
- 不在未确认远程地址前假设 GitHub/Gitee 或仓库名。
- 不删除其他 AI 正在编辑的未提交改动；只做快照式提交，不做 `reset --hard`、`clean`、强删。
- 实盘相关代码只允许 mock 测试，不触发真实券商操作。

## 对正式 spec 的影响
- 不改变业务功能需求。
- 需要新增多 AI git 协作文档；若用户确认，再同步 `INDEX.md`。
